# Common Room 360°

Interactive self-contained browser 3D common-room scene based on five user-supplied photographs and a rotating room video.

## Open

Open `room360/index.html`, or visit the repository's GitHub Pages URL if Pages is configured to serve the main branch root.

## Interaction

Drag horizontally to turn a full 360°, drag vertically to look up or down, scroll to zoom, use arrow buttons, and click reset to return to center. Full-screen mode is also supported.

## Reconstruction accuracy

The GitHub version is a simplified manually reconstructed 3D room, not an exact architectural model or LiDAR scan. A separate downloadable complete edition contains the original-photo gallery and a video-scrub real-world look-around mode, which requires binary video/photo assets not stored in this repository yet.
